Prueba del embed de agenda

Esta página NO se publica: es para probar el script a mano. Abrila con el servidor de desarrollo corriendo (npm run dev) y cambiá CAL_LINK abajo por tu usuario/evento. Los tres modos usan el mismo /embed/embed.js que se sirve en producción.

1. En la página

El calendario va adentro de un contenedor y crece con su contenido.

2. Ventana

Un botón abre el calendario encima de la página.

3. Botón flotante

El script agrega un botón fijo abajo a la derecha.

Eventos

Todo lo que el calendario le avisa a esta página. No debería aparecer ningún dato del formulario.
