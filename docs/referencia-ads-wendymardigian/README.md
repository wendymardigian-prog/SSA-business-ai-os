# Referencia visual del dashboard de Ads (repo wendymardigian)

Copia de solo lectura de los componentes del panel de Ads del repo `wendymardigian`
(React + Vite + shadcn + recharts), copiados el 10/10/2026.

Sirven SOLO como referencia visual para replicar el dashboard de Meta Ads de SSA
(ver el prompt `Prompt_Dashboard_Ads_Replica.md`). No se importan ni se compilan:
por eso tienen la extensión `.txt`, para que Next, TypeScript y ESLint los ignoren.

| Archivo | Qué es |
|---|---|
| AdsPanel.tsx.txt | Dashboard principal (la pieza central) |
| CampaignDetailPanel.tsx.txt | Detalle de campaña |
| AdDetailPanel.tsx.txt | Detalle de anuncio |
| AudienceInsights.tsx.txt | Audiencia edad/género + horario |
| FunnelViz.tsx.txt | Embudo |
| ads-utils.tsx.txt | PlacementCard y nombres de placements |
| useSortable.tsx.txt | Encabezados de tabla ordenables |
| Skeletons.tsx.txt | Esqueletos de carga |
| admin-shell.css.txt | Paleta y clases .admin-* del index.css |

Borrar esta carpeta cuando el dashboard nuevo esté terminado.
